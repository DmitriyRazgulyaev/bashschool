# Загрузка литературы и подготовка заданий с помощью ИИ

1. Только admin может создавать материалы, импортировать книги и публиковать фрагменты. Проверка роли выполняется на backend.
2. Администратор загружает UTF-8 TXT или вставляет текст и подтверждает права. Произведение сохраняется в materials.body.
3. Выделяются предложения (12–450 символов) или абзацы (12–1500 символов), максимум 500; сохраняются UTF-8 байтовые смещения.
4. Фрагменты получают review_status=draft. Задания выбирают только опубликованные фрагменты.
5. Кнопка генерации вызывает API внешней языковой модели с API-ключом, сохраненным исключительно на backend. Для конкретной языковой пары создаётся правильный и специально ошибочный вариант.
6. Администратор проверяет оба варианта и нажимает Опубликовать или Отклонить.
7. После публикации пользовательские ответы накапливаются и согласуются прежним механизмом голосования.
8. Для проверки качества языковой модели необходимы ручные тесты с носителями языка. Автоперевод нельзя считать эталоном.

Важно: если произведение защищено авторским правом, необходимо разрешение не только на публикацию, но и на передачу текста внешнему AI API. Настройка `AI_API_URL` доступна только администратору сервера.

Изоляция черновиков и исключение администраторов из рейтинга применяются через SQL, а не только Vue.
