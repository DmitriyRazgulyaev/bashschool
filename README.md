# bashschool — «Башкирская языковая школа»

Платформа парных переводов с геймификацией: веб + Telegram-бот + база переводов + REST API.

**Главный сценарий:** фрагмент → ежедневное задание → ответ → согласование → подтверждённый перевод.

Контракты API и схема данных: [`docs/arhitektura_i_kontrakty_api.pdf`](docs/arhitektura_i_kontrakty_api.pdf).

## Структура

| Папка | Что внутри | Кто |
|---|---|---|
| `backend/` | API на Go, схема PostgreSQL | бэкендер |
| `bot/` | Telegram-бот (Python, aiogram) | фронтенд/бот |
| `web/` | веб-интерфейс (Python, Streamlit) | фронтенд/бот |
| `data/` | фрагменты и ошибочные варианты (JSON) | данные/документация |
| `docs/` | документация | все |
